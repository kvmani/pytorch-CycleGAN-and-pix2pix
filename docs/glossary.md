# Glossary

## CycleGAN

An unpaired image-to-image translation method that learns mappings between two domains using adversarial and cycle-consistency losses.

## pix2pix

A paired image-to-image translation method that learns a mapping from input images to target images using conditional adversarial training.

## EBSD

Electron backscatter diffraction, a microscopy technique used to infer crystallographic information from diffraction patterns.

## Kikuchi Pattern

Diffraction pattern used in EBSD analysis. Denoising and enhancement must preserve band structure.

## Provenance

Metadata that explains how an artifact was generated, including code version, config, command, dataset, model, runtime, and timestamp.

## Artifact Manifest

A machine-readable inventory of files produced by a workflow.

## Dataset Leakage

Accidental sharing of related samples between train, validation, and test splits, causing overly optimistic results.

## Promoted Checkpoint

A checkpoint approved for documented scientific use after validation and registry review.
